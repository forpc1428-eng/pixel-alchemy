## Matching a reference site

When the user shares a URL (e.g. `vedant-bhayani.vercel.app` → black-hole journey, black UI, scientific HUD,
"Scroll to cross the event horizon"): note concept, palette temperature, type style, HUD idea, section rhythm, loader
and cue behaviour → choose the closest row above → re-create the *quality*, never the identity (no copied names,
text, logos or assets).
